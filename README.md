One Word From Grandma entry for the make.fun bounty of the same name. `main.ts` writes exactly one word to `/output/entry.txt` — the word a grandma would text about AI. Fully offline and deterministic: no network, no clock, no randomness, standard library only.

> robotthing

Why this word: a grandma who doesn't know the name for AI just calls the whole thing "robotthing" — one warm, baffled, run-together word, lowercase the way she types, tied straight to robots.

## Run it

```sh
node main.ts
```
